## Лабораторная работа №1 (4 ч)

**Тема:** Введение в рендер-пайплайн.

**Цель работы:** понять этапы рендеринга в Godot Engine и собрать базовую сцену курсового проекта.

**Задание:**
1. Создать проект, собрать 3D-сцену из примитивов или импортированных моделей (.glb) по теме курсовой.
2. Настроить камеру (перспектива/ортогональная, FOV, свободное управление).
3. Назначить материалы (StandardMaterial3D) и включить отладочные режимы Viewport (Wireframe, Overdraw, Unshaded).
4. Измерить FPS, draw calls, вершины через Profiler / Monitors; записать результаты до и после оптимизации (MultiMesh, LOD, удаление лишних объектов).

**Что должно быть по 3D-сцене:** сцена помещения (варианты 1-3, 6, 9, 11, 12, 15), оборудования (варианты 4, 5, 13, 14), территории (варианты 7, 8, 10).

## Лабораторная работа №2 (8 ч)

**Тема:** Модели освещения и тени.

**Цель работы:** освоить типы источников света, параметры теней и их влияние на восприятие и точность визуализации.

**Задание:**
1. Установить DirectionalLight3D, OmniLight3D, SpotLight3D; настроить энергию, цвет, радиус, затухание.
2. Включить тени, настроить разрешение, bias, количество каскадов (PSSM), сравнить качество и производительность.
3. Реализовать интерактивное управление источниками (перемещение, вкл/выкл, изменение параметров) через UI.
4. Добавить запечённое освещение (LightmapGI или VoxelGI/SDFGI) и сравнить с динамическим.

**Дополнительно:**
- солнце по времени суток (вариант 7), лампы и освещённость (варианты 1, 12), источники тепла/огня как свет (варианты 11, 15), подсветка зон (вариант 14).

## Лабораторная работа №3 (6 ч)

**Тема:** Окружение и пост-обработка.

**Цель работы:** научиться формировать атмосферу и визуальную читаемость сцены через WorldEnvironment и эффекты.

**Задание:**
1. Настроить WorldEnvironment: небо, ambient light, тонемаппинг, экспозицию.
2. Включить и настроить эффекты: туман (Fog / Volumetric Fog), Glow, SSAO, SSR, цветокоррекцию.
3. Реализовать переключение пресетов окружения через UI (например, «норма / авария / ночь»).
4. Сделать собственный пост-эффект через CanvasItem-шейдер на ViewportTexture (например, виньетка, контур, инверсия).

**Дополнительно:**
- дым и загрязнение через Volumetric Fog (варианты 8, 15), контуры выбранных объектов (варианты 4, 5, 12), атмосфера цеха или серверной (варианты 11, 13).

## Лабораторная работа №4 (6 ч)

**Тема: PBR-рендеринг и процедурные текстуры**

**Цель работы:** освоить физически корректные материалы (PBR) и генерацию текстур без растровых файлов.

**Задание:**
1. Создать 3-4 PBR-материала (albedo, metallic, roughness, normal, AO) для объектов сцены; проверить при разном освещении.
2. Сгенерировать процедурную текстуру (NoiseTexture2D или шейдер: шум, полосы, клетка, износ).
3. Применить процедурную текстуру как карту в материале (например, роughness или albedo).
4. Динамически менять параметры материала из скрипта в зависимости от состояния модели (нагрев, износ, загрязнение).

**Дополнительно:**
- сравнить PBR и простой материал на одной сцене;
- через PBR-материал отразить: состояние оборудования (варианты 4, 13, 14), материалы стен и мебели (варианты 2, 9), слои и маркировка в атласе (вариант 5), поверхности для отражения звука (варианты 3, 6).

## Лабораторная работа №5 (10 ч)

**Тема:** Вершинные и фрагментные шейдеры.

**Цель работы:** научиться писать шейдеры на Godot Shading Language для визуализации данных и эффектов.

**Задание:**
1. Написать vertex-шейдер с анимацией или деформацией (волна, пульсация, смещение по шуму).
2. Написать fragment-шейдер, окрашивающий поверхность по значению параметра (heatmap: градиент по значению, передаваемому через uniform или текстуру данных).
3. Реализовать шейдер выделения или среза (clip plane / dissolve / контур) с управлением из UI.
4. Передать данные из GDScript в шейдер (uniform, массивы, текстура данных) и обновлять в реальном времени.
5. Интегрировать результат в курсовой проект как основной модуль визуализации.

**Дополнительно:**
- поле освещённости, температуры, концентрации (варианты 1, 8, 11, 15), зоны слышимости и фронт волны (варианты 3, 6), послойный срез (вариант 5), рабочие зоны и коллизии (вариант 14), загруженность (вариант 10).
